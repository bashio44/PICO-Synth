# PICO synth

音の形を見ながら、シンセサイザーの基本を試せるブラウザーアプリです。音声処理はWeb Audio APIで行い、アカウントやアプリ用サーバーは必要ありません。

## 起動方法

必要なもの: Node.js 22以上、npm

```sh
npm ci
npm run dev
```

表示されたローカルURLをブラウザーで開きます。音を鳴らす前に「音の準備をする」を押してください。これはブラウザーの音声再生制限に対応するためです。準備後は画面の鍵盤、またはPCの `Z 1 X 2 C V 4 B 5 N 6 M`（低音域）と `A W S E D F T G Y H U J K`（高音域）で試奏できます。鍵盤はマウスとタッチに対応しています。

## できること

- 波形を選べる2基のオシレーター（サイン、矩形、ノコギリ、三角、ノイズ）、信号波形の図、音量、±48半音の粗調整とセント単位の微調整。発音中の音にも音量・音程・波形の変更を反映します
- OSC 2をOSC 1のFM変調に使う切替と変調深さ。OSC 2はFM使用中に単独では鳴らず、音量つまみが変調量になります
- 最大8音のポリフォニー（JSON設定では最大16音）。上限を超えると古い発音から解放します
- OSC 1とOSC 2それぞれのADSR数値入力（時間は1ms単位）とドラッグ可能な曲線表示。OSC 2は初期状態では無効で、通常はOSC 1の設定を両方に使います
- ピッチLFOと音量LFO（0.1〜30Hz、0.1Hz刻み）。対数スライダーと数値入力のどちらも小数点第一位で設定・表示でき、Web Audioの音声グラフで動作します。20Hzを超える音声レートも画面更新タイマーで近似しません。音量LFOはゲインが負にならない範囲に制限しています
- 初心者向けスタジオ画面と英語表記の「PRO SYNTH」画面を切替可能。ノブ、波形選択、トグル、鍵盤から同じ音色設定を編集できます
- 2オクターブ（C3〜C5）の鍵盤と、2段のPCキー入力に対応します
- 30種類の音色（先頭にピュアサイン波、後半にキック、スネア、ハイハット、クラップなどの打楽器）と、オリジナルMIDI演奏5曲をサンプルとして収録しています
- 「PRO FX RACK」では6種類すべてのエフェクト設定と信号配線を1画面で編集できます
- 標準MIDIファイル（SMF形式0／1）の読込み、再生、ループ、停止。先読みスケジューリングとベロシティに対応します
- ディストーション（Drive / Tone / Mix）、コーラス（Rate / Depth / Mix）、コンプレッサー（Threshold / Ratio / Knee / Attack / Release）、3バンドEQ（Peak / Notch / HPF / LPF）、ディレイ、リバーブ（Pre-delay / Decay / Mix）。信号経路に合わせた各プレビューをパラメーター変更に合わせて表示します。直列・並列・センドの配線と循環接続チェックにも対応
- ピアノ、管弦楽器、シンセ、打楽器など30種類のサンプル音色を、スタジオ／PRO SYNTHのどちらからでも選んで読み込めます。設定JSONは`public/presets/`にあります
- 5つのオリジナルMIDIサンプル（スケール、アルペジオ、ブルース、ドラムグルーヴ、ワルツ）を選んで読み込み、現在の音色で再生できます。通常MIDIファイルも引き続き読み込めます
- スキーマバージョン付きJSONによる音色、エフェクト、配線、MIDIノートの入出力

## MIDIの範囲

- `.mid` と `.midi` を読み込みます。ファイルは10MB以下、曲は1時間以内、ノートは100,000音以下です。
- 形式0／1に対応し、形式2（独立した曲を持つ形式）とSMPTE時間形式は読み込み時に案内して拒否します。
- 形式1のトラックはすべて同時にPICOの音色で再生します。テンポ変更はMIDI解析ライブラリが秒単位へ変換します。
- MIDIチャンネル、楽器プログラム、パン、コントロールチェンジは再現しません。外部MIDI機器向けのWeb MIDI APIにも対応しません。

## エフェクトと配線

標準Web Audioノードで構成し、AudioWorkletは使いません。コーラスは遅延＋LFO、リバーブはプリディレイとブラウザー内で作るインパルス応答を使います。ディレイの内部フィードバックは0〜0.8に制限します。一般のエフェクト循環配線は拒否し、配線の変更・JSONの読込み前に入口と出口、接続先、循環を検証します。MIDI停止時は発音中ノートを止め、エフェクトグラフを作り直して残響を消します。

## 対応環境と制限

- Web Audio APIと`AudioContext`に対応した最新のChrome、Edge、Firefox、Safariを想定しています。
- 音声の開始にはユーザー操作が必要です。OSやブラウザーの自動再生・音量設定も確認してください。
- スマートフォンでは縦向きの画面を想定したレイアウトになります。PCでは鍵盤の文字キーも使えます。
- ポリフォニー、MIDIサイズ、ノート数、パラメーター範囲に上限があります。端末の負荷やブラウザーの音声出力遅延は環境によって異なります。
- プリセット履歴、外部MIDI入力、MIDI楽器／CC再現、テンポ同期LFOは未対応です。

## テストとビルド

```sh
npm test
npm run build
npm run preview
```

Vitestの回帰テストでは、2オクターブの鍵盤と各種入力欄フォーカス・キーリピート・修飾キー、ADSRの精度と範囲、LFOの対数スライダーと直接入力、OSCごとのADSRとFM配線、発音中の音程・音量・波形・エンベロープ・LFO変更、ノイズの長時間ループ、全エフェクトの音声ノード設定とグラフ反映、MIDI解析、JSON検証と旧設定との互換性、配線の循環拒否、30種類すべてのプリセットと5つのMIDIサンプルの読込みを確認します。本番成果物は`dist/`に生成されます。

## GitHub Pagesで公開する

`.github/workflows/pages.yml`が`main`または`master`へのpush時にビルドし、GitHub Pagesへ公開します。初回実行時はGitHub ActionsからPagesの有効化も試みます。

公開URL: https://bashio44.github.io/PICO-Synth/

1. このプロジェクトをGitHubリポジトリへpushします。
2. Actionsから **Deploy to GitHub Pages** を実行し、完了後にPagesのURLを確認します。
3. リポジトリまたはOrganizationの設定でActionsによるPages有効化が許可されていない場合は、**Settings → Pages → Build and deployment** で **GitHub Actions** を選びます。

Viteは相対パス（`base: "./"`）でビルドするため、`https://<ユーザー>.github.io/<リポジトリ>/`のようなリポジトリ配下のURLでもアセットを読み込めます。
