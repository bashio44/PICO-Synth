# PICO synth

音の形を見ながら、シンセサイザーの基本を試せるブラウザーアプリです。音声処理はWeb Audio APIで行い、アカウントやアプリ用サーバーは必要ありません。

## 起動方法

必要なもの: Node.js 22以上、npm

```sh
npm ci
npm run dev
```

表示されたローカルURLをブラウザーで開きます。音を鳴らす前に「音の準備をする」を押してください。これはブラウザーの音声再生制限に対応するためです。準備後は画面の鍵盤、またはPCの `A W S E D F T G Y H U J K` キーで試奏できます。鍵盤はマウスとタッチに対応しています。

## できること

- 波形を選べる2基のオシレーター（サイン、矩形、ノコギリ、三角、ノイズ）、音量、半音とセント単位の音程調整
- 最大8音のポリフォニー（JSON設定では最大16音）。上限を超えると古い発音から解放します
- ADSRの数値入力とドラッグ可能な曲線表示。曲線はアタック／ディケイ／サステイン／リリースの再生値と対応します
- ピッチLFOと音量LFO（0.1〜2,000Hz）。Web Audioの音声グラフで動作し、20Hzを超える音声レートも画面更新タイマーで近似しません。音量LFOはゲインが負にならない範囲に制限しています
- 標準MIDIファイル（SMF形式0／1）の読込み、再生、ループ、停止。先読みスケジューリングとベロシティに対応します
- ディストーション、コーラス、コンプレッサー、EQ、ディレイ、リバーブ。直列・並列・センドの配線と循環接続チェック
- スキーマバージョン付きJSONによる音色、エフェクト、配線、MIDIノートの入出力

## MIDIの範囲

- `.mid` と `.midi` を読み込みます。ファイルは10MB以下、曲は1時間以内、ノートは100,000音以下です。
- 形式0／1に対応し、形式2（独立した曲を持つ形式）とSMPTE時間形式は読み込み時に案内して拒否します。
- 形式1のトラックはすべて同時にPICOの音色で再生します。テンポ変更はMIDI解析ライブラリが秒単位へ変換します。
- MIDIチャンネル、楽器プログラム、パン、コントロールチェンジは再現しません。外部MIDI機器向けのWeb MIDI APIにも対応しません。

## エフェクトと配線

標準Web Audioノードで構成し、AudioWorkletは使いません。コーラスは遅延＋LFO、リバーブはブラウザー内で作る短いインパルス応答を使います。ディレイの内部フィードバックは0〜0.8に制限します。一般のエフェクト循環配線は拒否し、配線の変更・JSONの読込み前に入口と出口、接続先、循環を検証します。MIDI停止時は発音中ノートを止め、エフェクトグラフを作り直して残響を消します。

## 対応環境と制限

- Web Audio APIと`AudioContext`に対応した最新のChrome、Edge、Firefox、Safariを想定しています。
- 音声の開始にはユーザー操作が必要です。OSやブラウザーの自動再生・音量設定も確認してください。
- スマートフォンでは縦向きの画面を想定したレイアウトになります。PCでは鍵盤の文字キーも使えます。
- ポリフォニー、MIDIサイズ、ノート数、パラメーター範囲に上限があります。端末の負荷やブラウザーの音声出力遅延は環境によって異なります。
- プリセット履歴、外部MIDI入力、MIDI楽器／CC再現、テンポ同期LFOは未対応です。

## テストとビルド

```sh
npm test
npm run build
npm run preview
```

重要なMIDI解析、JSONの値検証、ルーティング循環検出をVitestでテストしています。本番成果物は`dist/`に生成されます。

## GitHub Pagesで公開する

`.github/workflows/pages.yml`が`main`または`master`へのpush時にビルドし、GitHub Pagesへ公開します。初回実行時はGitHub ActionsからPagesの有効化も試みます。

1. このプロジェクトをGitHubリポジトリへpushします。
2. Actionsから **Deploy to GitHub Pages** を実行し、完了後にPagesのURLを確認します。
3. リポジトリまたはOrganizationの設定でActionsによるPages有効化が許可されていない場合は、**Settings → Pages → Build and deployment** で **GitHub Actions** を選びます。

Viteは相対パス（`base: "./"`）でビルドするため、`https://<ユーザー>.github.io/<リポジトリ>/`のようなリポジトリ配下のURLでもアセットを読み込めます。

## 依存関係

- [`@tonejs/midi`](https://github.com/Tonejs/Midi): ブラウザー内でMIDIファイルを解析し、テンポ変更を秒単位へ変換
- Vite、TypeScript、Vitest: 開発、型検査、テスト用（公開後の音声処理にサーバーランタイムは不要）
